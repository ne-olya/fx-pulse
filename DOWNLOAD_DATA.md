# Загрузка открытых данных ЦБ РФ и MOEX

Этот репозиторий хранит код загрузчиков, но не сами рыночные данные. Команды
ниже пишут CSV в `data/raw/`, который намеренно исключён из Git. Для повторения
нужны Python 3.12+ и [uv](https://docs.astral.sh/uv/).

```bash
make setup
```

## Быстрый запуск

Скачать официальные курсы ЦБ с 2018 года, дневную историю MOEX и доступную
10-минутную историю трёх валютных инструментов:

```bash
make data DATA_FROM=2018-01-01 DATA_TO=2026-09-02 CANDLE_FROM=2026-08-01
```

`CANDLE_FROM` задан отдельно, чтобы быстрый запуск не скачивал большой файл.
Для `CNYRUB_TOM` 3 сентября 2026 года через ISS проверена история 10-минутных и
часовых свечей с 15 апреля 2013 года. Глубина может отличаться у других бумаг.

По умолчанию берутся `CNYRUB_TOM`, `USD000UTSTOM` и `KZTRUB_TOM`. Другой набор
задаётся через `SECIDS`:

```bash
make data DATA_FROM=2024-01-01 DATA_TO=2024-12-31 \
  CANDLE_FROM=2024-12-01 SECIDS='CNYRUB_TOM USD000UTSTOM'
```

## Отдельные источники

### ЦБ РФ

```bash
uv run python -m fxpulse.data.cbr \
  --from 2021-09-03 --to 2026-09-02 \
  --currencies USD EUR CNY TJS UZS KGS KZT AMD \
  --output data/raw/cbr_daily.csv
```

Источник — `https://www.cbr.ru/scripts/XML_dynamic.asp`. В файле есть
`rate_date`, код валюты, `nominal`, `rate_rub`, время выгрузки и полный URL
запроса. Номинал сохраняется обязательно: например, курс может быть задан за
100 единиц валюты. `rate_date` — дата действия официального курса, а не
timestamp публикации; правило доступности для модели задаёт слой панели.

### MOEX ISS: дневная история

```bash
uv run python -m fxpulse.data.moex daily \
  --from 2021-09-03 --to 2026-09-02 \
  --secids CNYRUB_TOM USD000UTSTOM KZTRUB_TOM \
  --output data/raw/moex_daily.csv
```

Выход содержит OHLC, `waprice`, оборот, число сделок, `fetched_at` и URL
конкретной страницы ISS. История читается постранично; незавершённая загрузка
не перезаписывает предыдущий CSV.

### MOEX ISS: 10-минутные свечи

```bash
uv run python -m fxpulse.data.moex candles \
  --from 2026-08-01 --to 2026-09-02 \
  --secids CNYRUB_TOM \
  --chunk-days 31 \
  --output data/raw/moex_candles.csv
```

Время свечи берётся из `END`: значение считается известным только после её
закрытия. Для длинного интервала запрос разбивается на чанки по 31 календарному
дню; это снижает риск сетевых ошибок и ограничения размера ответа.

### Часовые свечи для эксперимента

```bash
make experiment-data EXPERIMENT_FROM=2018-01-01 EXPERIMENT_TO=2026-09-02
```

Команда сохраняет отдельные дневной и часовой файлы по `CNYRUB_TOM`. Часовые
свечи запрашиваются напрямую у MOEX с `interval=60`; собирать их из
10-минутных свечей не требуется. В текущем снимке эксперимента сохранены
26 181 часовая свеча за период с 3 января 2018 по 2 сентября 2026 года.

Проверка полной доступности ISS на 2 сентября 2026 года дала:

- 10 минут: 167 417 свечей, 15.04.2013–02.09.2026;
- 1 час: 36 341 свечу, 15.04.2013–02.09.2026.

Это фактический ответ API для `CNYRUB_TOM`, а не обещание MOEX о сроке
хранения. Для модели используем часовые данные с 2018 года; 10-минутный полный
файл сейчас не нужен.

Для синхронной проверки CNY, USD, KZT, золота и серебра:

```bash
make hourly-factor-data
```

Снимок содержит 99 455 часовых свечей за 2018–2026 годы и сохраняется в
`data/raw/moex_cets_factors_60m.csv`.

### Национальные банки Казахстана и Узбекистана

```bash
make recipient-bank-data
```

Официальные ответы по каждой дате кэшируются в
`data/raw/recipient_banks/cache/`, поэтому оборванная загрузка продолжается, а
не начинается заново. Компактный результат с USD и RUB пишется в
`data/raw/recipient_bank_daily.csv`: Узбекистан покрыт с 2018 года, Казахстан —
с 7 мая 2021 года. Дата запроса и дата активации курса хранятся отдельно;
перенесённый курс помечается `is_carried=true`.

### Общая исследовательская панель

После `make universe-data` объединить дневные ряды MOEX и восемь валют ЦБ без
заполнения пропусков:

```bash
make research-panel
```

Результат — `data/processed/research_daily_panel.csv`. Это join по дате для
анализа; модель обязана отдельно учесть реальное время публикации каждого ряда.

## Проверка и ограничения

```bash
make test
```

Тесты не требуют сети: они проверяют XML ЦБ, схему ISS, пагинацию, provenance и
атомарную публикацию файла. Нулевой `CLOSE` или отсутствие сделки не следует
подменять предыдущей ценой: это отдельное состояние качества данных. Официальный
курс ЦБ и close MOEX — исследовательские публичные ориентиры, а не курс
исполнения клиентского перевода.

Основные файлы: `src/fxpulse/data/cbr.py`, `src/fxpulse/data/moex.py` и
`Makefile`. Скрипт `scripts/fetch_moex.py` оставлен как короткая совместимая
точка входа для запуска MOEX-загрузчика.
