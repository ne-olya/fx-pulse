# UZS h=5: обогащение данных и авторесерч

Статус: исследовательский результат, не production-ready модель. История
2025–2026 годов уже просматривалась в предыдущих экспериментах, поэтому ниже
она называется pseudo-holdout, а не новым независимым тестом.

## Что решает модель

Целевой курс задан в рублях за один узбекский сум. Для клиента, который меняет
RUB на UZS, меньшая цена лучше.

Модель отвечает на вопрос: «появится ли в следующие пять торговых дней заметно
более выгодный курс, или ждать уже не имеет большого смысла?»

Обучающая метка — triple barrier 25/50 bps:

- `0`, если раньше других условий цена улучшилась хотя бы на 25 bps;
- `1`, если раньше цена ухудшилась на 50 bps либо улучшение на 25 bps не
  появилось до конца пятидневного окна.

Оценочная удача определяется проще и независимо от порядка движения:

```text
target = 1, если лучший будущий курс за 5 дней
            не выгоднее сегодняшнего более чем на 25 bps;
target = 0 в противном случае.
```

То есть CatBoost учится на траектории движения, а lift измеряется по
продуктовому regret-порогу 25 bps.

## Данные и признаки

Базовая панель содержит 20 581 дневную строку, пять коридоров AMD/KGS/KZT/TJS/UZS
и период 2010–2026. Главные целевые курсы — официальные курсы ЦБ РФ.

До 490 потенциальных модельных колонок объединяют:

- 91 базовый признак: momentum 1/3/5/10/20 дней, volatility,
  percentile/z-score, расстояние до локальных min/max, календарь;
- национальные валютные ноги через USD и относительное движение коридоров;
- CNY/RUB, KZT/RUB, золото, серебро, IMOEX, RTSI, ОФЗ;
- 82 прошедших quality gate инструмента MOEX из валют, акций, металлов,
  энергетики и агросырья;
- turnover, volume, число сделок, средний размер сделки, illiquidity и open
  interest там, где поля существуют;
- режимы рынка, cross-market divergence и event-индикаторы;
- 94 UZS-специфичных признака.

UZS-блок включает официальные USD/UZS, RUB/UZS и CNY/UZS, их изменения и
волатильность, ключевую ставку, CPI, международные резервы, платёжный баланс,
proxy текущих трансфертов, сезонность, относительную силу валютных ног и
макро-взаимодействия. Данные присоединяются только по `known_at` назад во
времени и имеют ограничение по максимальному возрасту. Пропуск остаётся
пропуском; через многолетний разрыв значение не протягивается.

В эксперимент не входят новости, клиентская история, реальный банковский
bid/ask, комиссия и спред. `secondary income, credits` — широкий proxy текущих
трансфертов, а не точное число розничных денежных переводов. Изменение резервов
и reserve-asset flow не трактуются как прямой ряд интервенций.

## Обучение и политика сигналов

Для каждого тестового года и каждого из пяти коридоров обучается отдельный
CatBoost. В train попадают только четыре предшествующих года. Последние пять
наблюдений перед тестом исключаются: их метка в момент начала теста ещё не была
бы известна. Imputer обучается только на train.

После моделей применяется межвалютная надстройка:

1. Score каждого коридора переводится в causal percentile относительно его
   предыдущих 60 score; минимум истории — 20 наблюдений.
2. Для UZS берётся `0.5 × percentile UZS + 0.5 × средний percentile остальных
   четырёх коридоров`.
3. Не меньше 75% подтверждающих валют должны находиться выше своей медианы, а
   стандартное отклонение их percentile не должно превышать 0.30.
4. Сигнал рассматривается в верхних 40% относительно прошлых consensus-score.
5. Cooldown — 3 календарных дня, максимум — два сигнала в неделю.

Основная метрика — same-week lift: hit rate сигналов делится на ожидаемый hit
rate случайных допустимых дней тех же недель. Raw lift сравнивает сигналы со
всеми днями OOT. Первый вариант строже и лучше отделяет модель от недельной
сезонности и изменения базовой частоты удачных дней.

## Зафиксированный результат

10 итераций авторесерча могли менять только ограниченный набор гиперпараметров
CatBoost. Ни одна итерация не улучшила заранее замороженный baseline; поэтому
оставлены исходные параметры: 100 деревьев, depth 5, learning rate 0.04, без
автоматических class weights.

| Период | Same-week lift | Raw lift | Сигналы | Попадания | Сигналов/неделю | Худший годовой same-week lift |
|---|---:|---:|---:|---:|---:|---:|
| Search 2022–2024 | 1.227 | 1.425 | 154 | 93 | 1.04 | 1.181 |
| Pseudo-holdout 2025–2026 | 1.291 | 1.549 | 101 | 55 | 1.22 | 1.253 |

На search hit rate сигналов равен 60.39%, а среди всех дней — 42.38%. На
pseudo-holdout — 54.46% и 35.15% соответственно. Это историческая оценка
выбора дат, а не accuracy всей классификации и не обещание клиентской выгоды.

Машиночитаемый итог лежит в
[`docs/results/uzs-enriched-autoresearch.json`](results/uzs-enriched-autoresearch.json).

## Воспроизведение

Установка и базовые данные:

```bash
make setup
make data DATA_FROM=2010-01-01 DATA_TO=2026-09-04
make universe-data-all UNIVERSE_FROM=2018-01-01 UNIVERSE_TO=2026-09-04
make research-panel
```

Точные команды UZS-загрузки и point-in-time нормализации приведены в
[`DOWNLOAD_DATA.md`](../DOWNLOAD_DATA.md). Затем базовая h=5 панель и
обогащение строятся так:

```bash
uv run python scripts/run_amd_h5_site_pipeline.py \
  --cbr data/raw/cbr_daily.csv \
  --market data/processed/research_daily_panel.csv \
  --output artifacts/base_h5

uv run python scripts/build_enriched_feature_panel.py \
  --features artifacts/base_h5/features_h5.csv \
  --moex-source data/raw/moex_universe/SNAPSHOT configs/moex_universe.json \
  --moex-source data/raw/moex_fixed_income/SNAPSHOT configs/fixed_income_universe.json \
  --key-rate data/raw/cbr_key_rate.csv \
  --uzbekistan-data data/processed/uzbekistan_point_in_time \
  --output artifacts/uzs_feature_enrichment_v2_repro2_20260905
```

`SNAPSHOT` должен быть полным manifest-gated каталогом соответствующего
загрузчика. Для exact frozen contract итоговый `features.csv.gz` должен иметь
SHA-256:

```text
e93d704b29eebc1a105d93639bd8af0b06ada12fbfe1f6fa3d9f97f544ab3d27
```

Checksum распакованного CSV:

```text
1db056054df874b5a31d17ab8b6813ece3592fdcb31bbe44fc6dce3f267c05cb
```

Скорер fail-closed проверяет frozen contract и запускается двумя независимыми
командами:

```bash
uv run python scripts/score_uzs_enriched_hyperparams.py --evaluation search
uv run python scripts/score_uzs_enriched_hyperparams.py --evaluation pseudo_holdout
```

Официальные файлы меняются у владельцев. В исходном прогоне использовались
следующие raw checksums: CBU daily rates `50b8aa82…`, policy table
`533b3853…`, historical CPI `33f2a556…`, current CPI `ebd5696f…`, reserves
`fbc3aaf0…`, BOP `1fd7f944…`. Для точного повторения нужны именно сохранённые
snapshot-файлы; свежая выгрузка проверяет код и методику, но может дать другой
feature SHA и не должна молча проходить frozen contract.

## Ограничения вывода

- Гиперпараметры выбирались на 2022–2024; 2025–2026 уже были просмотрены и не
  заменяют будущий или закрытый банковский holdout.
- Макропризнаки редкие и запаздывающие; большое число дневных строк не делает
  квартальные наблюдения независимыми.
- Результат рассчитан по официальному курсу, а не по фактическому клиентскому
  исполнению.
- Авторесерч не достиг целевого same-week lift 1.30 на search и не дал прироста
  к замороженному baseline.
