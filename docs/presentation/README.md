## Как пересобрать

```
npm install pptxgenjs
node build-final.js   # черновик защиты, 4 слайда
node build.js         # промежуточная версия, 13 слайдов
```

Ёмкость строки при кегле 30 — около 26 знаков на карточке шириной 5,5 дюйма и 59 знаков во всю ширину. Высота строки 0,5 дюйма. При правках текста высоту блоков надо пересчитывать, иначе вёрстка едет.

Оформление повторяет фирменный стиль «Альфа Будущее» из презентации кейсодателя: фиолетовые обложки, светло-серые контентные слайды с белыми карточками, красные акценты и шевроны, лаймовые чипы.

Шрифт — Arial: фирменный шрифт Альфа-Банка в сборочном окружении недоступен. При наличии лицензии заменяется в мастере слайдов одним действием.

## Содержание

Обложка · Проблематика · Постановка и критерии · Подход · Схема решения · Три находки в данных · Выполненные этапы · Первые результаты · Главный вывод · Риски · План работ · Команда · Вопросы

Версия обновлена после двух дополнительных волн и строгой перепроверки: 60 проверок/идей, 110 тестов и основной h=5 кандидат с межкоридорным подтверждением. На слайдах явно отмечено, что модель остаётся исследовательским кандидатом и требует нового hold-out.
