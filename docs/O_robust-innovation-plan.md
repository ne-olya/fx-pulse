# Перепроверка и новая волна гипотез

**Зафиксировано до запуска:** 04.09.2026 06:37 МСК.  
**Статус:** план зарегистрирован, результатов этой волны ещё нет.

## Зачем

Lift `1,36–1,45` выглядит многообещающе, но победители выбраны после большого перебора на одной истории. Прямого чтения будущего в признаках не найдено; главный риск — переобучение исследователя на тестовых результатах.

## Как перепроверяем трёх победителей

1. Пять повторных обучений с разными seed: результат не должен держаться на одной удачной инициализации.
2. Псевдо-hold-out: отдельно показываем 2022–2024 и 2025–2026. Это стресс-тест, а не настоящий новый hold-out, потому что мы уже видели эти годы.
3. Вложенный walk-forward: на каждом шаге вариант выбирается только по прошлым годам и проверяется на следующем.
4. Недельный cluster bootstrap: доверительный интервал относительно случайного дня той же недели.
5. Placebo со сдвинутой целью: разрушаем связь даты сигнала с результатом; lift должен исчезнуть.
6. Перенос между коридорами: сильной считаем только идею, которая повторяется не на одной валюте.

## Новые гипотезы без дополнительного перебора параметров

| Вариант | Идея |
| --- | --- |
| `tb_catboost` | Зафиксированный CatBoost и triple-barrier — контроль |
| `direct_regret_catboost` | Учить непосредственно вероятность небольшой переплаты |
| `sequence_catboost` | Учитывать форму последних десяти движений |
| `seed_mean` | Усреднять пять независимых CatBoost |
| `seed_lcb` | Сигналить только при высоком среднем скоре и небольшом разбросе между seed |
| `cross_model_mean` | Усреднять CatBoost, XGBoost и логистическую регрессию |
| `dynamic_model_average` | Онлайн повышать вес модели, которая лучше работала в недавнем прошлом |
| `multi_barrier_mean` | Требовать согласия трёх разметок с разной допустимой ошибкой |
| `vol_scaled_barrier` | Масштабировать границы разметки под текущую волатильность |
| `rolling_4y_catboost` | Забывать старые режимы и учиться только на последних четырёх годах |
| `regime_experts` | Отдельный эксперт для спокойного, трендового и шокового рынка |
| `analog_knn` | Искать похожие состояния только в прошлом и смотреть, чем они закончились |
| `horizon_consensus` | Пушить, только если модели нескольких горизонтов согласны |

Для всех вариантов одинаковы: цель `regret ≤ 25 бп`, горизонты `3/5/10`, cooldown 3 дня, не более двух пушей в неделю и один заранее заданный порог top-40% по прошлым скорам.

## Критерий сильного результата

Недостаточно одного большого raw lift. Кандидат должен одновременно дать не меньше 200 сигналов, `0,8–1,4` сигнала в неделю, raw lift не ниже `1,3`, lift против случайного дня той же недели не ниже `1,15`, lift не ниже `1,2` на 2025–2026 и ни одного года ниже `1,0`.

Даже прохождение этих ворот не разрешает продуктовый запуск. Окончательная проверка возможна только на данных, которые появятся после заморозки модели, либо на действительно внешнем закрытом hold-out банка.
