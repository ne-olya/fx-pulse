# Прототип клиентского пути

**Файл:** `transfer-flow.html` — открывается двойным кликом, зависимостей нет.
**Опубликован:** https://claude.ai/code/artifact/fe4f9fea-8f47-4011-92f8-60ed6f572b17

Кликабельный прототип на интерфейсе Альфа-мобайла. Собран по скриншотам актуальной версии приложения.

## Что показывает

| Шаг | Экран |
|---|---|
| 1 | Центр уведомлений с пушем о курсе |
| 2 | Три способа перевода, у каждого — сколько дойдёт |
| 3 | Экран перевода: выбор получателя, ввод суммы, блок курса |
| 4 | Подтверждение с зафиксированным курсом |

Переключатель **«Момент упущен»** показывает сценарий, когда клиент открыл пуш через час и курс успел измениться.
Переключатель **«Зарплатный цикл»** — экран, где рыночный сигнал пересекается с окном клиента: сообщаем только в его дни переводов.

## Что интерактивно

- Нажатие на уведомление ведёт в перевод
- Получатель раскрывается списком сохранённых; выбор подставляет его способ перевода
- Способ переключается на самом экране перевода
- Сумма вводится с клавиатуры, есть быстрые суммы 500 / 1 000 / 2 000 ₽
- Всё пересчитывается на лету, включая комиссию 1 % по переводу на счёт
- В сценарии «момент упущен» — экран, где клиент сам выставляет нужную сумму
- Шкала уровня курса: три состояния относительно последних 90 дней, только внутри приложения
- Экран «Сообщать о курсе»: дни переводов клиента против режима «в любой день»

## Что мы добавляем к текущему приложению

Один блок «Получатель получит» с суммой в валюте получателя и курсом.

Сегодня курс встречается в пути **один раз** — мелким серым текстом на переводе по номеру счёта. На переводе по номеру телефона, помеченном бейджем «Быстро», курса нет вообще: клиент вводит рубли и не знает, сколько дойдёт.

## Числа и данные

**Курс исполнения** из приложения: 100 AMD = 25,94 ₽. Не курс ЦБ — спред между ними 8,9 %, и подстановка курса ЦБ завышает результат на четверть. Ошибку нашла персона в прогоне, см. [push-texts.md](../push-texts.md), раздел 3.

**Сумма 15 000 ₽** — круглая и выше верхней оценки среднего перевода. Оценки расходятся от 5,6 до 13 тыс. ₽, надёжной цифры нет; круглая сумма честнее ложной точности, а взята она выше середины намеренно: сумма в валюте получателя должна ощущаться. 15 000 ₽ — это 26 % месячной зарплаты в Армении и 113 % в Таджикистане. У клиента с историей подставляется его собственная сумма; 15 000 ₽ — значение по умолчанию для клиента без истории.

**Все реквизиты вымышленные.** Персональных данных нет.
