### Как проверить воспроизводимость

Репозиторий: https://github.com/ne-olya/fx-pulse

```bash
make setup
make data
make test        # включая 50 срезов против заглядывания вперёд
make backtest

uv run python -m fxpulse.signal_cli --date 2026-06-10   # сигналы на дату среза
```

## Все девять обязательных результатов закрыты

Последними закрылись пункты 1 и 9 — коммит `c1c7f25` от 06.09.

**Расчёт сигнала на произвольную дату среза** работает для продуктовой модели, а не только для библиотеки правил. Проверено фактическим прогоном: дата из списка срабатываний даёт сигнал, соседний день — нет, дата за пределами периода возвращает пустой результат вместо выдуманного, обращение до 20:00 МСК отвечает «скор ещё не доступен», подмена файла отклоняется по хешу.

**График курса с отметками срабатываний** — 30 отметок за последний год в прототипе, из той же выгрузки.

```bash
uv run python -m fxpulse.signal_cli --date 2026-06-10 --grid configs/frozen_uzs_indicator.json
```
