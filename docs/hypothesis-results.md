# Реестр проверок гипотез

Этот документ — журнал проверок, а не витрина лучших чисел. Все результаты
сохраняются в `artifacts/hypotheses/`; изменение модельного пакета разрешено
только через `configs/hypotheses.json`, SHA-256 которого записывается в
`run_meta.json` до интерпретации результата.

## Общий протокол

* Ряд: дневное закрытие `MOEX:CNYRUB_TOM`; для H4 — 10-минутные свечи того же
  инструмента. Это ликвидный открытый рыночный якорь, а не фиксинг ЦБ.
* Out-of-time период: 2021-09-03—2026-09-02 для дневных правил; H4 имеет
  свечи по 2026-09-03. Метрики также выводятся отдельно за каждый год.
* Метка и метрики соответствуют `prototype-brief.md`: цена в будущем должна
  остаться не хуже (``favorable``) либо через горизонт вырасти
  (``window_closing``). Главный срез ниже — `h=5` торговых наблюдений.
* H11/H12 каждый календарный месяц заново обучаются на расширяющейся прошлой
  выборке. Из её хвоста вычищаются пять наблюдений; текущий месяц не участвует
  в fit. В неделю берётся первый уже известный скор выше 90-го процентиля
  обучающей выборки.
* Кандидат на дальнейшую валидацию должен одновременно показать lift не ниже
  1.30, положительную forward-выгоду, частоту не менее 0.5 сигнала в неделю и
  отсутствие заметного годового провала. Это исследовательский порог, а не
  решение о запуске: без наблюдаемых исполнимых котировок приложения ни одно
  правило нельзя считать продуктовым сигналом.

## Вывод на этом этапе

На открытом ежедневном и внутридневном рыночном ряде нет правила, которое уже
доказало бы, что его можно превращать в пуш. Особо важные отрицательные
результаты — продолжение падения после momentum/downside-сигналов и отсутствие
добавочной ценности у активности торгов. Следующий поиск должен оставаться
вне этого набора: например, отдельно проверять календарные режимы и правила
комбинации уже неотобранных базовых индикаторов в nested walk-forward, а не
ослаблять пороги H13--H15 по тем же пяти годам.
