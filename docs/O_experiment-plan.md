# План эксперимента с сигнальной моделью

## Короткий словарь

- **Валютный коридор** — направление перевода, например RUB → TJS.
- **Котировка (курс)** — цена одной единицы иностранной валюты в рублях. В нашей записи чем курс ниже, тем выгоднее клиенту.
- **Свеча** — данные о рынке за один период, например час или день: цена в начале (`open`), максимум (`high`), минимум (`low`), цена в конце (`close`) и объём торгов (`volume`).
- **Доходность / изменение курса** — относительное изменение цены между двумя моментами, обычно в процентах.
- **Волатильность** — насколько сильно курс колеблется за выбранный период. Высокая волатильность означает большие и частые движения, но не указывает их направление.
- **Спред** — разница между ценой покупки и продажи валюты. У банка также есть разница между рыночным курсом и курсом для клиента. Данных о спреде Альфа-Банка в эксперименте нет.
- **Перцентиль** — положение текущего курса среди прошлых значений. Например, 10-й перцентиль означает, что курс был ниже только примерно в 10 % наблюдений.
- **Признак** — число, доступное модели на момент решения: изменение за три дня, волатильность, перцентиль, объём и т. п.
- **Таргет / метка** — правильный исторический ответ, оказался ли момент выгодным после того, как стало известно будущее.
- **Горизонт `h`** — сколько часов или дней после момента решения используется для проверки метки.
- **Скор модели** — оценка уверенности модели. Он является вероятностью только после калибровки.
- **Сигнал** — итоговое решение системы в момент `T`: основание найдено, скор выше порога и ограничения на отправку соблюдены.
- **Hit rate** — доля сигналов, которые подтвердились.
- **Lift** — отношение hit rate модели к hit rate случайного дня. `Lift = 1` означает отсутствие улучшения; `1,3` — точность выше базовой на 30 %.
- **Базисный пункт (бп)** — `0,01 %`. Сто базисных пунктов равны `1 %`.
- **Утечка (look-ahead)** — использование при расчёте признаков информации, которая ещё не была доступна на момент `T`.
- **Walk-forward** — последовательная проверка: обучаемся на прошлом, тестируем на следующем периоде и затем сдвигаем границу вперёд.
- **Cooldown** — минимальная пауза между двумя пушами.

## 1. Цель

Проверить, можно ли по открытым данным MOEX находить объяснимые моменты для перевода, которые на новых периодах точнее случайного дня и дают клиенту положительную выгоду.

Основная гипотеза: после фильтрации понятных рыночных индикаторов модель достигает устойчивого `lift ≥ 1,3` без слишком частых и кучных сигналов.

## 2. Данные

Делаем два независимых эксперимента:

1. **Основной:** часовые свечи `CNYRUB_TOM` (`interval=60`). Одна строка — одна завершённая часовая свеча.
2. **Контрольный:** дневные свечи `CNYRUB_TOM`, цена `close`. Одна строка — один торговый день.

MOEX фактически отдаёт для этого инструмента 10-минутные и часовые свечи с 15 апреля 2013 года. В первом эксперименте используем единый отрезок с 2018 года; полные 10-минутные данные пока не скачиваем, потому что модель работает с часами.

Курс ЦБ используем только для сопоставления. До расчётов проверяем полноту истории, дубли, пропуски, часовой пояс, ликвидность и фактическую доступность цены на момент `T`.

## 3. Разметка и признаки

Разметку создаём автоматически скриптом по правилам из [O_labeling.md](O_labeling.md).

Основной таргет:

```text
good_now_h = 1 — в будущем окне h не появился заметно более низкий курс;
good_now_h = 0 — ожидание дало заметно более выгодный курс.
```

Горизонты:

- для дневных данных: `1/3/5/10/20` торговых дней;
- для часовых данных: `1/4/8/24` следующих торговых свечи. Дневные горизонты проверяем отдельно на дневном датасете, чтобы не смешивать часы и торговые сессии.

Признаки считаем только по прошлому: изменения курса за несколько периодов, перцентили, расстояние до минимума, волатильность, диапазон свечи, час и день недели. Объём и число сделок добавим, если источник отдаст их заполненными; в первой часовой выгрузке они пустые. Будущие значения и метки в признаки не включаем.

## 4. Временное разбиение

Точные годы зависят от фактической полноты данных. Базовая схема:

```text
ранний период      — обучение;
следующий год      — выбор порога;
ещё следующий год — тест без заглядывания вперёд.
```

Такое разбиение повторяем по годам в режиме walk-forward. Между частями оставляем зазор не меньше горизонта метки. Первый запуск остаётся исследовательским: его результаты уже просмотрены, поэтому для честного финального подтверждения понадобится новый нетронутый период.

## 5. Что сравниваем

1. Случайный день или час — базовая линия.
2. Простые правила: низкий перцентиль, движение несколько периодов подряд, разворот от минимума, высокая/низкая волатильность.
3. Logistic Regression — простой интерпретируемый ML-бейзлайн.
4. Random Forest и XGBoost — более сложные модели для сравнения.
5. GRU — только дополнительный эксперимент, если часовых данных достаточно и остаётся время.

Для объяснимости модель не отправляет пуш без понятного основания. Каждый сигнал хранит код сработавшего индикатора, его фактические значения и скор модели. Первый запуск также сохраняет общую важность признаков; объяснение вклада признаков в каждый отдельный скор нужно добавить до продуктовых пушей.

## 6. Как скор превращается в сигнал

```text
сработал разрешённый индикатор
+ скор модели выше выбранного порога
+ закончился cooldown
+ не превышен недельный лимит
= итоговый сигнал
```

Порог выбираем на validation-периоде, а не на финальном тесте. Цель — около 1–2 сигналов в неделю без длинных серий.

## 7. Метрики и решение

Для каждого горизонта считаем:

- hit rate и lift относительно случайного момента;
- выгоду в базисных пунктах;
- число сигналов в неделю;
- кучность и интервалы между сигналами;
- устойчивость по walk-forward периодам;
- калибровку вероятностей модели.

Эксперимент можно считать успешным, только если на новом закрытом периоде получены устойчивый `lift ≥ 1,3`, положительная выгода и приемлемая частота. Если результат держится только в отдельных режимах, формулируем правило, когда система молчит. Если ни один подход не проходит критерии, фиксируем честный отрицательный результат без подгонки порогов.
