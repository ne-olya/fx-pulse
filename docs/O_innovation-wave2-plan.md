# Вторая волна: усиление устойчивости

**Зафиксировано до запуска:** 04.09.2026 06:59 МСК.
**Статус:** целевой follow-up после первой новой волны; это не независимое подтверждение.

Первая волна показала, что лучше всего переносятся короткая обучающая история, динамическое усреднение моделей и согласие нескольких barrier-разметок. Вторая волна проверяет только восемь заранее записанных комбинаций — без новой сетки параметров.

| Вариант | Что проверяем |
| --- | --- |
| `continuous_tb_catboost` | Порог продолжает жить между годами, а не обнуляет историю 1 января |
| `continuous_rolling_4y` | То же для модели, обученной на последних четырёх годах |
| `recency_dynamic_average` | Онлайн выбирать между длинной и короткой историей по уже созревшим меткам |
| `robust_three_mean` | Среднее трёх наиболее устойчивых семейств первой волны |
| `robust_three_unanimous` | Пуш только при одновременной высокой позиции всех трёх семейств |
| `leave_one_corridor_consensus` | Усилить сигнал, если в тот же день согласны остальные валютные коридоры |
| `causal_stacking` | Мета-модель обучается только на прошлых OOT-прогнозах и проверяется на следующем году |
| `economic_loss_catboost` | Сильнее штрафовать в обучении дни, где ложный пуш стоил бы много базисных пунктов |

## Более строгая статистическая перепроверка

- Недельный bootstrap первой волны повторяется блоками по четыре недели: окна будущего на 5–10 дней пересекаются, поэтому отдельные недели нельзя считать полностью независимыми.
- Дополнительно считаются сигналы без пересечения: следующий сигнал разрешён не раньше чем через `h` календарных дней.
- Для прежних победителей показывается намеренно консервативная верхняя граница Bonferroni по всем 13 379 просмотренным строкам. Это завышает штраф, потому что варианты зависимы, но хорошо показывает цену большого перебора.

Главным остаётся вложенный walk-forward первой волны. Follow-up может предложить более сильного кандидата, но не может превратить уже просмотренные 2025–2026 годы в настоящий hold-out.
